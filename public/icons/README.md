# Học Vui app icons

`hoc-vui-icon-master.png` is the 1254×1254 source artwork for the local PWA
icon family. It uses the Học Vui orange fox, teal explorer scarf and gold
compass on a solid deep teal/navy background. The fox is kept inside the central
safe area so the 512px maskable variant survives launcher cropping.

The served derivatives are resized from that master without changing the
artwork:

| File | Size | Use |
| --- | ---: | --- |
| `favicon-32.png` | 32×32 | Browser tab favicon |
| `icon-180.png` | 180×180 | Apple touch icon |
| `icon-192.png` | 192×192 | Android/PWA launcher |
| `icon-512.png` | 512×512 | Regular PWA launcher |
| `icon-512-maskable.png` | 512×512 | Maskable PWA launcher |

These files are install-surface artwork only. They do not replace the existing
fox, brand plaque, lesson or collection artwork under `public/art/`.
