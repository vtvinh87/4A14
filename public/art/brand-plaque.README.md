# Brand plaque artwork

The current production plaque is `brand-plaque-clean.png`. It was generated with the built-in imagegen tool as a transparent, premium 3D wooden signboard for the Học Vui adventure UI.

The image itself contains the exact two-line title, so the app no longer draws a separate HTML wordmark over the wood:

- `HỌC VUI`
- `Lịch sử & Địa lí 4`

The direction combines stacked walnut planks, beveled yellow/cyan toy lettering, brass details, compass and map accents, and restrained foliage. The fox mascot is intentionally excluded from this plaque to reduce repeated fox imagery in the header. The file has an alpha channel and is precached by the service worker.

`brand-plaque-wow.png` is the earlier version with a fox above the sign; it is retained for historical comparison and is no longer used by the app.

`brand-plaque.png` is the earlier blank-wood source kept for historical comparison; it is no longer used by the app.
