# Portrait world background

Generated with the built-in imagegen tool using `world-background.png` as the visual reference. This 1086 × 1448 opaque portrait composition is intended for tablet portrait orientation: clear sky in the upper third for the fixed header, an open central reading area, and a welcoming path in the lower third above the fixed dock.

It contains no UI, text, logo, mascot, character or watermark. `WorldScene` selects it through a native `<picture>` source when the viewport orientation is portrait; landscape continues to use `world-background.png`.
